# Sitt Naing Portfolio

A calm, modern React portfolio for Sitt Naing, an aspiring UI/UX designer based in Singapore.

## Profile positioning

Sitt's portfolio positions him as an aspiring UI/UX designer who learns by building usable prototypes. The site highlights calm visual systems, interaction design, deployed creative web experiences, and practical automation projects.

## UX structure

- Clear hero positioning with proof points and contact CTA
- About section focused on design identity, builder mindset, and project range
- Case-study format for each project: role, timeline, problem, approach, outcome, tools, and insight
- Accessible interaction states, visible focus styles, skip link, responsive layout, and reduced-motion support
- Live demo badges and direct project links where public deployments exist

## Featured work

- AirDraw 3D Studio: webcam hand tracking and view-aligned 3D air drawing — https://air-draw-3d.vercel.app/
- AI Social Content Pipeline: queue-backed backend for AI content planning, approval, publishing, and analytics
- Still Here: local-first breakup recovery companion with personalization, quests, and reflective tools — https://no-more-broken.vercel.app/
- Forever Yours: cinematic interactive proposal site with motion-led story moments — https://foreveryours-psi.vercel.app/
- Telegram Auto-Reply Assistant: personal Telegram reply automation with rules, cooldowns, allow/block lists, and optional AI

## Design direction

Minimal and soft, with interactive project switching, motion-tuned visual elements, glassy cards, warm neutrals, and muted accent colors. The work section now focuses only on the main product/project builds from Cursor sessions.
